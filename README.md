# AI-TZ Detector: Прототип для выявления коррупционных рисков в ТЗ по 44-ФЗ

**Направление хакатона:** 02. Выявление и мониторинг коррупционных рисков в конкретных сферах (государственные закупки).
**Команда:** irina-hakaton-blip
**Ссылка на прототип:** https://irina-hakaton-blip.github.io/ai-tz-detector/ *(примечание: ссылка заработает после включения GitHub Pages)*

## 📌 Описание проекта
**Проблема:** Ручная проверка технических заданий (ТЗ) на предмет ограничения конкуренции (нарушения ст. 33 44-ФЗ) отнимает много времени и человеческих ресурсов, при этом сложные или замаскированные нарушения часто упускаются.
**Решение:** Веб-приложение, которое автоматически анализирует текст ТЗ с помощью 4-слойного конвейера (парсер -> Rule-Engine -> Локальный RAG -> LLM-аудит) и выдает отчет с указанием конкретных нарушений и ссылками на нормативные акты.

## 🚀 Инструкция запуска
Прототип представляет собой клиентское веб-приложение (HTML/CSS/JS). Для запуска не требуется установка сложного серверного окружения.

**Способ 1 (Самый быстрый):**
1. Скачайте папку с проектом (или сделайте `git clone`).
2. Откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Edge, Яндекс.Браузер).

**Способ 2 (Через локальный сервер):**
